# Modular room v1

Generated for OuterNet with the built-in image_gen tool, 2026-10-24. Exact per-image prompts and original output paths are recorded in generation.json; raw outputs are retained in raw/. No downloaded or third-party furniture art is used.

The shell and available furniture types are separate images. The table lamp and balcony pine are not yet included in this first layout. Duplicate instances reuse the same image. Preparation uses world/tools/pixel_clean.py: nearest-neighbor, shared look.js palette, no dithering, trimmed transparent padding and binary-alpha furniture edges.

Preview: /?scene=modular&art=1. Press P, select Furniture, then drag centers or resize corners. Mirror and Duplicate work per object. Copy scene JSON exports placement. The original W0 room and scene are preserved.
