
# Progress 2026-10-24

Pipeline: the room is built and rendered once in Blender by a Python script (beauty, depth, camera and light data); the page draws the creatures live in three.js on top with a matching camera, using the depth to hide them behind furniture. Creatures become chunky 3D blocks from the approved pixel designs. The cabin and apartment move to later. W0 spec sections 4, 5, 7-10 and design.md updated.
